# 1RaceClub

The user's F1 YouTube channel: a live reaction to each F1 session, cut to a ~15 min long video, plus
Shorts (TikTok, YouTube Shorts, Reels) cut from it.

## Read order
1. [Main principles](../PRINCIPLES.md)
2. [principles.md](principles.md): the channel's why (`RC-n`)
3. [memory/MEMORY.md](memory/MEMORY.md): facts; open only what the task needs
4. [shorts-rules.md](shorts-rules.md): **read before editing a Short**: principles, rules today, agent
   checklist and open gaps
5. [workflow-log.md](workflow-log.md): the evidence, episode by episode
