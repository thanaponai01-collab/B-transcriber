- **Where:** V1 keeps the clip at 100% (linked to A1). Framing goes on a **video-only copy on V2**, one per V1 piece,
  for every Short. *(confirmed by the user's redo, 2026-11-27: Short 3 was moved from V1 to V2 copies)*
- **Switching who is in frame:** **cut the V2 copy** at the switch and give each piece its own Motion. **Never
  Position keyframes.** *(confirmed, 2026-11-27: "on the key frame i dont want that, when i change i cut … if
  keyframe … if cut, so its complicated")* Cut V2 only, never V1/A1.
- **Shot sizes:** studio wide two-shot → Motion Scale **374**, one host in frame. Single-person close-up camera
  → Scale **241–246**. *(seen, Shorts 1–3)*
- **Placement:** face **centred horizontally** (nose at x ≈ 0.5 of the frame), nose at about **42% of frame
  height**. *(seen: the user re-set every position the agent gave; the agent had faces slightly left and high)*
  The user's CFD 99 values: Short 2, left host about [1.57, 0.29], right host about [-0.80, 0.43]. Short 3,
  left host about [1.62–1.75, 0.29–0.33], right host about [-1.04 to -1.25, 0.35–0.44]. Values depend on the
  camera and where people sit, so check a frame.
- **Who's in frame:** the host who is talking, or reacting, in that stretch; while the phone caller talks,
  a listening host. Hold a framing for one to three pieces. *(seen; the user changed several of the agent's picks)*
- **Check:** export a frame per piece and compare it with Short 1's frames.

**Why it matters:** keyframes break when the user cuts the clip later. Off-centre faces were all redone by hand.
