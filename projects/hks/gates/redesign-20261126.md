# HKS rules redesign (2026-11-26): what was built, what it proved, what is yours to decide

**Goal:** one registry is the source of every HKS rule. Stage skills are generated from it. The CutDeck
helper and panel enforce the handover gates, which replaces the Stop hook.

**Status:** built on branch `feat/hks-rule-registry` and proven live on 2026-11-26 (Premiere 27.0.0,
run `output/verify-cutdeck/runs/20261126-163421-hks-gates`, copies in `data/redesign-20261126/live/`). Tests are green (pytest 1711, node 846).
The Stop hook is removed.

## Yours to decide (observations only; I decided none of these)

1. **Which rules are human-only.**
   - The extraction proposed 166 do–confirm, 11 code gate and 4 human-only.
   - So the handover asks for 154 written answers today. The panel shows "154 answers missing" on
     1125 v1.
   - The do–confirm experiment says answers don't judge taste. Story and endings look like
     human-only candidates.
   - 90 entries are unconfirmed candidates (HKS-1..33 study items, the agent-written pages).
2. **Which rule wins in each contradiction.**
   - The extraction lists 23 possible pairs (`registry/EXTRACTION.md`).
   - The whole-rules pass found real ones:
     - cover on the exact cut vs split cuts 0.5–2 s off;
     - "no camera change within 1 s" vs J/L offsets;
     - "cut host jokes" vs "add fun";
     - rule 3 "cut recap" vs "recap moved to the end";
     - the log's "clock always blurred" vs "clock fine on studio frames";
     - the log's "film damage on all B-roll" vs HKS-C10.
   - No supersession was set for any of them.
3. **Block vs label for a failed control.**
   - Set to label on 2026-11-25. **Nothing reads `late_draft_policy` now**: the Stop hook was its
     only reader. Block has no mechanism in the helper.
   - Observed: under the helper, a failed draft is red on the panel whatever the agent writes, so
     "label" holds without the agent. Block would need something that stops the agent's "ready"
     in chat, which only a session hook can see.
4. **May the agent override its own failed control?**
   - Today yes, with a reason, recorded and shown on the panel row ("N overridden").
   - Override is the only way to turn a failed control green.
   - The 1125 K23 handover called a failing number "intended".
5. **What counts as "a draft".**
   - Every marker was tried.
   - Only GUID + day baseline survives rename, label and duplicate.
   - The baseline also marks your own new sequences (e.g. "2 FACEBOOK D1 Copy 01") as new and ungated.
6. **Whether M-6 moves into PRINCIPLES.md.**
   - M-6 is in the registry (`rules/M-6.json`, unconfirmed).
   - Its claim, "a correction becomes a gate; a gate stays only if it catches something", held here
     in one way: a mutation test found a kept control failing a final, which the lifecycle demotes.
7. **Acceptable token and time cost per draft.** Measured:

   | Item | Cost |
   |---|---|
   | `hks_handover` | about 20–40 s live (save, parse and gates). No model tokens |
   | Panel poll | 4 command-log lines per 30 s; the parse runs only on a new save |
   | Stage skill per stage | 1.9k–9.9k tokens |
   | 154 written answers | inferred ~5–10k tokens of agent output per draft |
   | Correction check (each new correction against the rules) | $0.02–0.18 |
   | Rejected for cost or effect | the blind endings reviewer: $0.30–1.47 per draft, kappa ≈ 0 |
